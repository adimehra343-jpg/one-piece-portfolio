## 🚀 How to Run & Preview

### Option 1: Direct Browser Launch (Zero Setup)
Simply open `index.html` in any modern web browser (Google Chrome, Microsoft Edge, Brave, Firefox, or Safari):
```bash
# On Windows PowerShell
Start-Process "index.html"
```

### Option 2: Local Static Server (Python)
```bash
cd C:\Users\sanje\.gemini\antigravity\scratch\one-piece-portfolio
python -m http.server 3000
```
Then visit `http://localhost:3000`.

### Option 3: Vite Development Server
```bash
cd C:\Users\sanje\.gemini\antigravity\scratch\one-piece-portfolio
npm install
npm run dev
```
